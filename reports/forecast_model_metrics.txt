HOW TO READ THESE RESULTS
============================================================
- MAE: average size of the miss, in units per day. RMSE: similar, but
  large misses count more, so spikes in demand raise it.
- The naive baseline copies today's sales. A model is only useful if it
  beats this simple rule; the verdict above says whether it did here.

LIMITATIONS
- One-step-ahead (next day) forecasts only; not a multi-week forecast.
- One test window of 28 days, 90 product-store series, one random seed,
  no cross-validation and no hyperparameter tuning. A different window
  could rank the models differently.
- Many rows have zero sales (intermittent demand), which makes daily
  errors noisy for any model.
- Prices, discounts and inventory are not model inputs, so these results
  say nothing about promotion effects. Feature importance is not causation.
- Identifiers were excluded, so the model cannot learn item-specific
  behaviour beyond what recent sales and calendar features reveal.
